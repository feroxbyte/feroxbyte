# Hi, I'm Batuhan

I'm the creator of **[Sohedra](https://sohedra.com)**: Svelte for the web and for native apps.
Software engineer in Istanbul, working on it full time.

## Sohedra

- **UI components:** headless, accessible components for Svelte and SvelteKit.
- **Router:** a typed router for client-side Svelte apps.
- **Native apps:** a framework that builds iOS and Android apps from Svelte, rendering real
  native views through [Lynx](https://lynxjs.org).

The components and the router keep one API on the web and in native apps. Sohedra is open source
(Apache-2.0) and early. If it helps you, [sponsor the work](https://github.com/sponsors/feroxbyte).

**Stack:** TypeScript, Svelte, SvelteKit, Lynx, Cloudflare Workers.
